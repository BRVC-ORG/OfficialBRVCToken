# Early BRVC Community Token → Official BRVC Token Distribution Proposal

## Purpose

This document captures an early community idea for how the existing community-created BRVC token could potentially relate to a future official BRVC token.

The goal is to create a transparent runway between the current BRVC community and any future official BRVC token or utility ecosystem developed by BRVC.

This is a proposal for discussion only and is not yet a finalized commitment, allocation model, or token distribution plan.

---

## Background

There is currently a community-created BRVC token on Solana/Pump.fun that formed organically around Brock, BRVC, and the broader Satoshi narrative.

Separately, BRVC may develop an official token with actual utility, formal tokenomics, and deeper integration into the BRVC ecosystem.

Rather than treating the current community token and a future official BRVC token as completely unrelated, one idea is to explore a transparent mechanism that recognizes early community participation.

---

## Proposed Direction

The existing BRVC community token could potentially serve as an early community participation layer leading into the future official BRVC token.

Possible approaches could include:

- Recognizing eligible holders of the existing BRVC token during the official token distribution
- Using one or more transparent blockchain snapshots
- Allocating a defined portion of the official token supply to the early BRVC community
- Creating a migration, claim, or conversion mechanism
- Rewarding long-term community participation rather than only short-term speculation
- Publishing all eligibility rules and distribution mechanics before implementation

The specific approach, allocation percentage, snapshot rules, and eligibility requirements would need to be designed and agreed upon later.

---

## Why Consider This?

### Reward Early Community Participation

The existing BRVC community formed before the official token architecture was finalized.

Recognizing that community could create continuity between the early grassroots phase and the eventual official BRVC ecosystem.

### Build a Runway Toward the Official Launch

The existing token and community can help build awareness, discussion, content, and engagement while BRVC continues developing its official products and token utility.

Over time, this could create a natural transition:

**Community BRVC → BRVC development and utility → Official BRVC token**

### Reduce Fragmentation

A future official BRVC token could otherwise leave the existing community token disconnected from the project.

A transparent community-recognition mechanism could help bring the early community forward rather than simply replacing it.

### Improve Transparency

Any relationship between the community token and the official token should be discussed publicly and documented wherever possible.

Clear documentation can reduce confusion about:

- what is official vs. community-created
- what holders should expect
- how distribution decisions are made
- how early community participation is recognized

---

## Important Distinction

The current BRVC token is a community-created token and should not be represented as the official BRVC token unless BRVC formally makes that designation.

Holding the current BRVC token does not currently guarantee:

- an allocation of the future official BRVC token
- a specific conversion ratio
- financial returns
- equity in BRVC
- revenue sharing
- any other economic right

Any future relationship between the community token and the official BRVC token would need to be formally defined, documented, and approved.

---

## Questions to Resolve

1. Should current BRVC holders participate in the official token distribution?
2. If so, what percentage of the official supply should recognize the early community?
3. Should eligibility be based on a single snapshot or multiple snapshots over time?
4. How should short-term buyers, bots, insiders, and concentrated wallets be treated?
5. Should participation duration matter?
6. Should the current token be migrated, claimed against, or simply used as one input into distribution?
7. What utility will the official BRVC token ultimately provide?
8. How should BRVC distinguish official communications from community-run token activity?

---

## Current Status

**Status: Early discussion / proposal**

No final distribution mechanism has been selected.

The immediate goal is to document the idea transparently, gather input, and determine whether this approach aligns with the eventual design and utility of the official BRVC token.
